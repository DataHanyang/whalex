# Skill: frontend-aesthetic-direction

**트리거**: 브랜드/디자인 시스템이 없는 그린필드 작업에서 "어떤 룩으로 갈지"를 정해야 할 때.

**목적**: AI 기본 하우스스타일(크림 배경·세리프 타이틀·테라코타 액센트)을 선제 차단하고, 의도된 비주얼 방향을 확정한다.

## 절차

### 1단계 — 4방향 탐색
서로 다른 축으로 4개의 방향성을 제시한다 (예시):
- **A. 모노크롬 미니멀**: 단색 팔레트 + 여백 위주, 타이포로 승부
- **B. 다크 임팩트**: 진한 배경 + 단일 강렬 액센트(레드/옐로), 대형 숫자
- **C. 페이퍼/에디토리얼**: 따뜻한 종이 톤 + 명조 계열 + 세리프/산세리프 페어링
- **D. 그리드 테크**: 그리드 라인·모노 스페이스·엣지 있는 카드

각 방향마다 **팔레트 4–6색(이름 포함)** 과 폰트 페어링, 간격 스케일을 구체적으로 명시한다.

### 2단계 — 사용자 선택 후 커밋
- 선택받은 방향의 팔레트·폰트·간격을 `theme.js` 또는 DESIGN.md에 **토큰으로 고정**한다.
- 이후 모든 결과물은 이 토큰만 사용한다. 중간에 색을 갈아엎지 않는다.

### 3단계 — 반 AI-슬롭 선언
- 선택한 방향에서 금지할 관용구를 명시한다 (예: "그라디언트 금지", "이모지 금지", "Inter 금지").
- 이 리스트는 `ai-slop-check` 스킬의 검증 기준이 된다.

## 산출물
- 확정된 방향성: 팔레트(이름+헥스) · 폰트 페어링 · 간격 스케일 · 금지 리스트 · 1줄 모티프 설명.
