# Skill: flier

**트리거**: 전단지·포스터·안내문 등 **인쇄용 단면 1장** 요청.

**목적**: 프린트 대화상자에서 정확히 1페이지로 나오는, 3초 안에 읽히는 전단을 만든다.

## 페이지 설정

- 자체 `@page` 규칙으로 용지를 고정한다 (WhaleX에는 페이지 스타터가 없다):

```html
<style>
  @page { size: A4 portrait; margin: 0; }   /* 또는 letter */
  html,body { margin:0; }
  .page { width:210mm; height:297mm; overflow:hidden; position:relative; }
  @media print { .page { page-break-after: avoid; } }
</style>
<div class="page">…전단 전체…</div>
```

- **풀블리드 고정 박스**: 넘친 내용은 잘리지, 2페이지로 흐르지 않는다. A4와 letter 어느 쪽으로 뽑아도 깨지지 않게 안쪽 여백을 매 변 최소 4% 확보한다.
- `vh`/`vw` 금지 — 창 크기를 따라가지 용지를 따라가지 않는다.
- PDF가 필요하면 Edge headless 인쇄(`msedge --headless --print-to-pdf`)로 뽑고 결과를 확인한다.

## 전단의 문법 — 지나가며 3초

- **지배 요소 하나**: 대개 6단어 이하 헤드라인. 방 건너편에서 읽히는 크기(페이지 높이의 ~8% 이상)로, 나머지는 확실히 종속되게.
- **5W 묶음**: 무엇·언제·어디서·비용·행동 1개(QR 크기 URL, 전화번호)를 흩뿌리지 말고 한 덩어리로 스캔 가능하게.
- **플랫 컬러 블록 + 벡터 도형** 위주. 사진·그라디언트보다 강한 대비, 본문은 밝은 종이에 근검정.
- **여백이 단어보다 힘이 세다**: 계층이 한눈에 안 들어오면 카피를 더 자른다.
- 옵션: 하단 tear-off 프린지 (좁은 셀 나열 + 점선 왼쪽 보더 + 회전된 연락처 텍스트) — 사용자가 원할 때만.

## 검증

- 인쇄 미리보기 기준: 잘린 것 없음, 2페이지로 넘친 것 없음.
- **그레이스케일로 뽑아도 성립**하는 대비인지 확인 (색약·흑백 복사 대응).
