# Skill: accessibility-audit

**트리거**: 결과물 전달 전 접근성 점검이 필요할 때. 덱·문서·HTML 모두 해당.

**목적**: WCAG 기준 위반을 찾아 리포트로 남긴다. **전수 보고**(신뢰도/심각도 포함) 후 집계에서 필터링한다 — "중요한 것만" 지시 금지.

## 점검 항목

### 1. 명암비 (핵심)
- 텍스트 vs 배경 실제 값 계산 (색상 대비 공식):
  - 본문/일반: ≥ 4.5:1 (AA)
  - 대형(18pt+/24px+): ≥ 3:1
  - 캡션/각주/페이지 번호: ≥ 4.5:1 권장 (최소 4.6:1 실측 기준)
- 라이트 배경의 액센트 색 텍스트가 4.5:1 미만이면 **accentDark(딥 버전)로 교체** 판정.
- 다크 배경의 소형 컬러 텍스트는 1차 텍스트(흰색)로 교체 판정.

### 2. 의미론/구조 (HTML)
- 제목 레벨 순서(h1→h2→h3), `<table>` 진짜 표 사용, 이미지 alt.
- 키보드만으로 모든 흐름 도달 가능.

### 3. 포커스·모션
- 포커스 링 존재, `prefers-reduced-motion` 대응.

### 4. 미디어
- 영상 슬라이드: 재생·정지 접근, 파일 존재.
- 스크린샷: 캡션으로 보완.

## 리포트 형식
```
[심각도: High/Med/Low] 위치(슬라이드 N / 셀렉터) — 문제 — 권장 조치 — 기대값(예: 4.5:1)
```
- 신뢰도(확실/추정) 표시. 추정은 재확인 단계를 명시.
- 모든 항목을 나열한 뒤 요약(High 몇 건, Med 몇 건)과 우선순위 조치 3개.
