# Skill: hierarchy-rhythm-review

**트리거**: 결과물의 시각적 계층과 리듬(간격) 점검. polish-pass의 전 단계로 주로 실행.

**목적**: 계층이 의도대로 작동하는지, 간격이 스케일 시스템을 따르는지 확인한다.

## 점검 항목

### 1. 계층 (Hierarchy)
- 화면/슬라이드당 텍스트 계층이 4단계 이하인가? (kicker → title → body → caption)
- 크기·가중치·색·위치 중 **2개 이상의 축**으로 계층이 구분되는가? (크기만으로 구분되면 흐릿함)
- 첫 눈에 핵심 메시지가 3초 안에 보이는가?

### 2. 리듬 (Rhythm)
- 간격이 스케일 단위로 떨어지는가? (0.25/0.5/0.6 in 등 — 무작위 값 금지)
- 같은 의미의 요소(카드들, 표 행) 사이 간격이 일관적인가?
- 그리드 정렬: 카드·텍스트·이미지의 수직/수평 정렬선이 일치하는가?

### 3. 밀도 (Density)
- 정보 밀도가 청중에 맞는가? (교육 교안 = 여백 확보, 대시보드 = 밀집 허용)
- 공백이 "의도된 여백"인가, "채우기 실패"인가?

### 4. 숫자·데이터
- tabular numerals 사용, 단위 분리 없음, 소수점·콤마 일관성.

## 리포트 형식
```
[슬라이드 N] 요소 — 문제 — 권장 조정값 (예: 카드 간격 0.25→0.4in, 타이틀 26→30pt)
```
- 심각도 분류. 계층 붕괴(High) / 리듬 불일치(Med) / 미세 조정(Low).
