# Skill: component-extract

**트리거**: 기존 결과물에서 재사용 가능한 컴포넌트(카드·헤더·버튼·표·배지)를 인벤토리로 뽑아야 할 때.

**목적**: 반복 요소를 컴포넌트 단위로 분리해 일관성과 재사용성을 확보한다.

## 절차

### 1단계 — 반복 탐지
- 여러 슬라이드/페이지에 걸쳐 2회 이상 등장하는 요소를 찾는다: 헤더 밴드, 키커+타이틀 조합, 카드, 배지, 버튼, 표 스타일, 페이지 번호, 각주.

### 2단계 — 스펙 문서화
각 컴포넌트에 대해:
- 이름 + 사용처 (예: `headerBand` — 라이트 슬라이드 상단 0.55in 미드나잇 블랙 밴드)
- 크기·좌표 규칙, 색 토큰, 폰트 크기, 상태(버튼이면 hover/disabled)
- 파라미터 (예: `{kicker, pageNum, dark}`)

### 3단계 — 코드 분리
- 컴포넌트를 레이아웃 코드(layouts.mjs)의 재사용 함수로 구현. 데이터(JSON)와 분리.
- HTML 환경이면 React 컴포넌트로 분리하고 `Object.assign(window, {...})`로 공유.

### 4단계 — 적용 점검
- 모든 사용처가 동일 컴포넌트를 쓰는지 확인. 하드코딩된 중복(색·크기 인라인 값)을 찾아 토큰/컴포넌트로 교체한다.

## 산출물
- 컴포넌트 인벤토리 표 (이름·사용처·파라미터·상태) + 구현 코드 경로.
