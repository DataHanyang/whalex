# Skill: ai-slop-check

**트리거**: 결과물에서 "AI 티" 나는 관용구를 탐지할 때. 전달 전 모든 결과물에 기본 적용 권장.

**목적**: AI 슬롭 관용구를 규칙 기반으로 탐지해 제거한다. AI 생성 슬롭을 의도된 디자인과 구분하는 게 목적이므로, **의도된 사용은 리포트에서 제외**하고 근거를 남긴다.

## 탐지 규칙

1. **공격적 그라디언트 배경** — 2색 이상의 강한 대비 그라디언트가 배경/카드에 사용된 경우 (브랜드 로고 등 의도된 경우 제외).
2. **이모지 장식** — 텍스트 요소가 아닌 곳의 이모지 (⚠️✅🚀 등). 브랜드에 명시적으로 있는 경우만 허용.
3. **왼쪽 보더 + 라운드 카드** — 컨테이너 왼쪽에 컬러 보더 + 라운드 코너 조합 (AI 생성의 대표 관용구).
4. **Inter 만능 폰트** — 라틴 텍스트가 전부 Inter(또는 기본 시스템 폰트)인 경우. 폰트 페어링이 없으면 지적.
5. **하우스스타일 패턴** — 크림 배경 + 세리프 디스플레이 타이틀 + 테라코타/앰버 액센트 조합 (현행 모델의 기본 미학).
6. **장식용 이모지/아이콘 도배** — 정보를 더하지 않는 아이콘 남발.
7. **SVG로 그린 슬롭 일러스트** — 의미 없는 파도/산/사람 형상 SVG.
8. **중복 숫자/통계 남발** — 의미 없는 수치 배치 (data slop).
9. **진부한 문구** — "혁신적인 솔루션", "원활한 워크플로우" 류의 템플릿 문구가 본문을 차지하는 경우.

## 절차

1. 결과물 스캔 (XML 파싱 또는 HTML 검사).
2. 매칭 결과를 규칙 번호 + 위치 + 실제 값으로 리포트.
3. 각 항목에 "의도된 사용 여부" 판정: 의도된 경우 근거 명시 후 통과, 아닌 경우 교체 제안.
4. 수정 후 재스캔 (2회차부터는 신규 항목만 보고).

## 산출물
- 탐지 리포트 + 수정 제안. 수정은 의도된 디자인 원칙에 따라 한다 (제거하거나, 브랜드 토큰 기반으로 재설계).
