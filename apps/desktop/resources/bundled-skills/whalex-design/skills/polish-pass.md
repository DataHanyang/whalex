# Skill: polish-pass

**트리거**: 모든 작업의 최종 게이트. 산출물 전달 직전에 항상 실행.

**목적**: 전체 리뷰를 총괄해 통과/재작업을 판정한다.

## 절차

### 1단계 — 체크리스트 총괄
다음을 전부 돌린 뒤 종합한다:
- `accessibility-audit` — 명암비·구조·키보드
- `ai-slop-check` — AI 관용구
- `hierarchy-rhythm-review` — 계층·리듬
- `interaction-states-pass` — 상태 (인터랙티브일 때)
- 기계 검증: 텍스트 넘침, 좌표 안전 영역, 종횡비, 미디어 존재, 중복 이미지

### 2단계 — 커버리지 우선 판정
- 각 검토는 전수 보고(신뢰도/심각도 포함) 후 집계한다. "대충 중요한 것만" 보고하지 않는다.
- High 건이 있으면 **재작업** — 수정 후 검토 1건만 재실행(전체 반복 금지).
- High 없음 + Med 3건 이하 → **통과** (Med는 수정하거나 다음 이터레이션에 명시).
- Low는 우선순위 목록으로 전달.

### 3단계 — 로드 검증
- HTML: 콘솔 오류 0, 페이지가 즉시 오류 없이 로드되는가.
- PPTX: 파일이 열리고(압축 무결성) 미디어가 참조되는가. 가능하면 렌더링 이미지로 스폿 체크.

### 4단계 — 전달 요약
- **극도로 간결히**: 한계점(caveats)과 다음 단계만. 전체 요약 반복 금지.

## 통과 기준 요약

| 항목 | 기준 |
|---|---|
| 오류 | 0건 (로드·콘솔) |
| 명암비 | 본문 4.5:1, 대형 3:1 |
| 넘침/겹침 | 0건 |
| AI 슬롭 | 의도되지 않은 관용구 0건 |
| 일관성 | 모든 화면이 DESIGN.md 토큰 사용 |
