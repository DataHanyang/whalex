# Skill: wireframe

**트리거**: 최종 디자인 전에 구조를 빠르게 탐색할 때, 또는 정보 아키텍처가 확정되지 않았을 때.

**목적**: 저해상도로 3개 이상의 레이아웃 변형을 탐색해 사용자가 구조를 고르게 한다.

## 절차

### 1단계 — 콘텐츠 인벤토리
- 넣어야 할 콘텐츠 요소를 전부 나열한다 (텍스트 블록, 이미지, 표, CTA, 각주).
- 순서는 제안하되 사용자 확인을 받는다.

### 2단계 — 3+ 변형
- 동일 콘텐츠를 서로 다른 구조로 배치한다:
  1. **표준 그리드** — 예측 가능한 카드/열 구조
  2. **비대칭/스태거드** — 한쪽 치우침, 대형 숫자·이미지 강조
  3. **풀블리드** — 배경 이미지/밴드가 화면을 지배, 텍스트는 위에 오버레이
- 각 변형은 회색조 와이어프레임 수준(스타일 없음)으로 빠르게 그린다.

### 3단계 — 비교 제시
- 변형을 나란히 보여주고 장단점을 한 줄씩 설명한다. 사용자가 고르거나 섞도록 유도한다.
- 선택된 구조는 다음 스킬(make-a-deck / make-a-prototype)의 레이아웃 템플릿이 된다.

## 규칙
- 와이어프레임 단계에서는 색·폰트·그림자·장식을 넣지 않는다. 구조만 본다.
- 자리 표시자는 회색 박스 + 라벨로 충분하다. lorem ipsum 금지.
