# Skill: generate-variations

**트리거**: 하나의 결과물에 대해 "다른 방향도 보고 싶다"거나, 사용자가 옵션을 요구했을 때.

**목적**: 서로 다른 축으로 3개 이상의 고해상도 변형을 만들어 사용자가 섞고 고르게 한다.

## 절차

### 1단계 — 축 정의
변형을 만들 축을 명시적으로 정한다. 같은 축에서 겉만 다른 변형을 만들지 않는다.
- 비주얼(색 처리, 톤, 질감)
- 타이포(크기 대비, 폰트 페어링, 자간)
- 구성/레이아웃(그리드, 비대칭, 풀블리드)
- 인터랙션(전환, 호버, 상태)

### 2단계 — 명세 기반 생성
- 변형마다 **명시적 스펙**을 먼저 쓴다 (팔레트·폰트·간격·레이아웃 규칙). 무작위성에 기대지 않는다 — temperature 파라미터가 없는 세대는 명세가 곧 다양성이다.
- 기본(by-the-book, 기존 패턴 준수)에서 출발해 점점 창의적인 변형으로 간다.

### 3단계 — 비교 표면화
- 변형을 나란히(design_canvas) 또는 트윅 토글로 제시한다.
- 각 변형의 장단점을 한 줄씩, 어떤 맥락에 어울리는지 설명한다.

### 4단계 — 병합 유도
- 사용자가 "A의 색 + B의 레이아웃"처럼 섞기를 원하면 즉시 병합본을 만든다.

## 규칙
- 브랜드 토큰이 있으면 모든 변형이 그 토큰 안에서 움직인다 (이탈 금지).
- 변형 수는 3–5개. 그 이상은 선택을 방해한다.
