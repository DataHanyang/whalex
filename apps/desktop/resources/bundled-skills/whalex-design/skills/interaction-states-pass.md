# Skill: interaction-states-pass

**트리거**: 인터랙티브 결과물(HTML 프로토타입·웹)의 상태 처리를 점검할 때.

**목적**: 모든 인터랙티브 요소가 의도된 상태를 갖는지 확인한다.

## 점검 매트릭스

모든 인터랙티브 요소(버튼·링크·입력·토글·탭)에 대해:

| 상태 | 확인 |
|---|---|
| **default** | 비활성 상태에서도 라벨/목적이 명확한가 |
| **hover** | 커서 반응(색·그림자·스케일)이 미묘하고 즉각적인가 |
| **active** | 클릭 순간 피드백(누름 효과)이 있는가 |
| **disabled** | 회색 처리 + 커서 금지 + 라벨 유지 — "왜 비활성인지" 알 수 있는가 |
| **focus** | 키보드 포커스 링이 명확한가 (WCAG 2.4.7) |
| **loading** | 비동기 동작 시 스피너/스켈레톤 표시 — 더블 클릭 방지 |
| **validation** | 입력 오류 시 색+아이콘+메시지로 알리는가 (색만으로 알리지 않음) |

## 추가 확인
- 히트 타깃 ≥ 44px (모바일).
- hover/focus 시 상태가 시각적으로 겹치지 않는가.
- 전환(transition)이 150–300ms 범위인가. 과한 애니메이션은 `prefers-reduced-motion`에서 제거되는가.

## 산출물
- 요소별 상태 커버리지 표 + 누락 상태와 수정 제안.
