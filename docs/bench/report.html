How this was measured

  • Same prompt, same machine. Each CLI got the identical task text in a clean directory on one Windows 11 box, running full-auto (no human approvals).
  • Tokens come from the tools themselves — Whalex's usage snapshot, codex exec --json turn totals, and claude -p --output-format json. Claude Code's own total_cost_usd is used for its cost since it bills sub-agent usage too; the others are computed from published rates (Whalex $0.435 / $0.87 per 1M in/out; Codex $5.00 / $30.00 per 1M in/out; Claude $5.00 / $25.00 per 1M in/out).
  • Correctness is graded, not eyeballed. The LeetCode task runs against 48 hidden tests. The visual tasks are checked for the requested features and then rendered in a real browser engine to confirm the page draws and animates.

Honest notes

  • Whalex's first steam-locomotive attempt failed: the scene rendered but the train never appeared. That failure is what prompted adding a verify_page tool so the agent renders and inspects its own output; the run shown here is the one that used it.
  • Codex could not run in its own sandbox on this machine (its Windows sandbox helper failed every write with an ACL error), so it was run with the OS sandbox disabled — the same full-auto condition as the other two.
  • Claude Code's Earth run hit the 25-minute cap while still refining, so its cost is an estimate: token counts are read from the session transcript, and the pure Opus-rate total is scaled by 0.608 — the ratio between Claude Code's self-reported cost and the same reconstruction on the locomotive task, where both numbers exist (Claude Code routes some sub-work to Haiku, so a straight Opus reconstruction overstates the bill). Its artifact was finished and scores 100%; an earlier attempt at the same task ended after a single turn without writing anything.
  • Prices move. Rates were verified on 16 Aug 2026 and a DeepSeek promotional discount was in effect; recheck each vendor's pricing page before quoting these numbers.
  • This is a small benchmark — four tasks, one run each. It shows order-of-magnitude cost differences reliably; it does not settle which model is "smarter".
